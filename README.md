# JGSM Church Website

Elegant, responsive static website for JGSM Church Ministries, focused on worship, Bible teaching, remote-area mission, and community service.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish with GitHub Pages

1. Push these files to the repository's `main` branch.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, select **GitHub Actions**.
4. The included workflow publishes the site automatically.

Expected URL: `https://sandeep3003.github.io/JGSMChurch/`

## Content to update

Search `index.html` for “placeholder” and update church address, service times, phone, email, social links, church history, pastor details, and ministry information.
